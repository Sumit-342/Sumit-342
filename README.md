### 📂 Featured Projects

#### 🧮 Numiq – AI Math Solver
*An AI-powered math solving platform combining symbolic math with LLM reasoning.*
<a href="https://numiq-ai.vercel.app" target="_blank">
  <img src="https://img.shields.io/badge/Live_Demo-Numiq-00ffcc?style=for-the-badge&logo=vercel&logoColor=black" alt="Numiq Live Demo" />
</a>

- Multi-stage pipeline: SymPy (symbolic solving) + Groq/Llama (classification) + Gemini (fallback & explanations)
- Handles equation solving, word problems, and step-by-step explanations
- FastAPI backend, vanilla JS frontend, OCR.Space for image-based input

#### 📊 Retail Sales Forecasting Dashboard
*An end-to-end retail forecasting system with a multi-page analytics dashboard.*
<a href="https://sales-forecasting-dashboard-sumit.streamlit.app/" target="_blank">
  <img src="https://img.shields.io/badge/Live_Demo-Streamlit-FF4B4B?style=for-the-badge&logo=streamlit&logoColor=white" alt="Retail Dashboard Live Demo" />
</a>

- Forecasting with **Prophet, SARIMA, and XGBoost**
- Anomaly detection (Isolation Forest, Z-Score) and demand segmentation (K-Means + PCA)
- Dark glassmorphism UI across Sales Overview, Forecast Explorer, Anomaly Report, and Product Segments pages

#### 🤖 Project Lucy – AI Desktop Companion
*Evolved from an emotion-detection NLP model into a full PySide6 desktop companion app.*

- Full reminder lifecycle state machine with floating message-card windows
- Custom walk-in/walk-out animations and background operation on Windows
- Originally built on TF-IDF + Logistic Regression for Hinglish emotion detection

#### 📄 AI Resume Analyzer
*A Streamlit app that scores resumes and suggests best-fit roles.*
<a href="https://sumit-resume-analyzer.streamlit.app/" target="_blank">
  <img src="https://img.shields.io/badge/Live_Demo-Streamlit-FF4B4B?style=for-the-badge&logo=streamlit&logoColor=white" alt="Resume Analyzer Live Demo" />
</a>

- Role-based scoring with missing-skill detection
- Basic ATS-style evaluation with visual insights

#### ❤️ Heart Disease Prediction App
*A Machine Learning web app deployed using Streamlit.*
<a href="https://heart-disease-predictor-342.streamlit.app/" target="_blank">
